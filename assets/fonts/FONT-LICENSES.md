# Local fonts

Fonts retrieved from Google Fonts CSS for Inter, Roboto, Lato, Montserrat and Urbanist. WOFF2 files are unmodified font subsets (Latin, Latin Extended and Vietnamese where available). CSS only changes URLs to local files.

Each family is distributed under its upstream SIL Open Font License. Full notices and license text are in `licenses/Inter-OFL.txt`, `Roboto-OFL.txt`, `Lato-OFL.txt`, `Montserrat-OFL.txt`, `Urbanist-OFL.txt`.

Upstream: https://github.com/google/fonts — family directories `ofl/inter`, `ofl/roboto`, `ofl/lato`, `ofl/montserrat`, `ofl/urbanist`.
